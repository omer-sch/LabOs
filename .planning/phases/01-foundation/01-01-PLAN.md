    Initialize Supabase local stack (Supabase CLI must be installed; if not: `brew install supabase/tap/supabase`):

    ```
    npx supabase init
    npx supabase start
    ```

    Create `.env.local` with:
    ```

    DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:54322/postgres?pgbouncer=true&connection_limit=1"
    # Direct URL for Prisma migrations (bypasses pooler)
    DIRECT_URL="postgresql://postgres:postgres@127.0.0.1:54322/postgres"

    # Clerk — fill in from Clerk dashboard
    NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_REPLACE_ME
    CLERK_SECRET_KEY=sk_test_REPLACE_ME

    NEXT_PUBLIC_CLERK_AFTER_SIGN_UP_URL=/dashboard
    ```
